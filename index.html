PowerWatch: Smart Grid Anomaly Detection

A real-time dashboard that watches electrical sensor readings (voltage, current, frequency, temperature) and flags unusual values as warnings or critical faults.

  • Detects anomalies with a z-score over each sensor’s last 50 readings, so no fixed thresholds are needed
  • Shows live readings in animated charts and logs every fault in a searchable history page
  • Admin panel to manage sensors, protected by a login with bcrypt password hashing
  • REST API for sensors, readings, anomalies and login, plus a WebSocket stream for live data
